# DD-130 — ¿Se asienta `firebase/php-jwt` para validar el `idToken` de Google?

**Qué hay que decidir.** ADR-0005 dice que el servidor valida el `idToken` de Google, pero no dice con qué. El agente
del servidor usó `firebase/php-jwt` 7.2.2. Es licencia BSD-3, y lo mantiene la organización de Google en GitHub (grado
E, `SIN VERIFICAR` en esta sesión).

Con esa librería, el servidor valida:
- la firma, contra las llaves públicas de Google, guardadas en caché;
- el emisor, el cliente y el vencimiento, más el sujeto y el correo.

Se descartó `google/apiclient`, que trae todo el cliente de las API de Google. Sin ADR, la dependencia no tiene
respaldo (`CLAUDE.md` §5).

**Opciones.**

1. **Asentar `firebase/php-jwt`** en una adenda corta de ADR-0005.
2. **Cambiar a `google/apiclient`,** que es más pesada y tiene su propio método de verificación.

**Recomendación.** De Claude: la 1, porque ya está implementada y probada (27 tests de registro-E16 y E17). Una
recomendación no es la decisión.

**Respuesta.**

Claude, por delegación de Arthur (C-236; decisión 21 de [[acta-2026-11-20-modelo-y-pasarela]]): la opción 1. Queda en la
adenda del 2026-11-21 de [[ADR-0005-autenticacion]].
