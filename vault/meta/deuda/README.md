# Deuda de decisión, una nota por decisión

Desde el 2026-11-20 cada decisión pendiente nueva es una nota `DD-NNN.md` aquí, hecha con
`plantillas/plantilla-deuda-de-decision.md`. Así dos personas pueden abrir decisiones a la vez sin chocar
en la misma tabla. Las filas anteriores siguen en `meta/deuda-de-decision.md`.

Antes de tomar un número, `git pull` y el siguiente libre después del mayor que haya aquí o en la tabla.
La CI falla si un número se repite. Regla completa: `formas-de-trabajo/colaboracion-en-el-vault.md`.
