# DD-138 — ¿La licencia del catálogo de códigos postales de Correos de México permite usarlo en el producto?

**Qué hay que decidir.** El municipio y la colonia se asisten con el Catálogo Nacional de Códigos Postales de
Correos de México (SEPOMEX), cargado en la base con el comando `direcciones:cargar-catalogo`. Las condiciones de uso
de ese archivo no se han verificado (grado E, `SIN VERIFICAR`).

**Qué hacer:** que Nadir verifique que se puede usar en un producto comercial y si pide atribución.

**Si no se puede:** la colonia vuelve a ser solo texto y el municipio sale de otra fuente oficial, por ejemplo el
catálogo de claves geoestadísticas del INEGI.

**Recomendación.** De Claude: verificarlo antes de `publicacion`. En desarrollo se usa con datos locales.

Una recomendación no es la decisión.

**Respuesta.**
